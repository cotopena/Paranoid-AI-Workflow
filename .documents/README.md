# `.documents`

This directory holds the staged workflow artifacts.

Key folders:

- `.documents/issues/` for local mirrors of external issues or pasted requests
- `.documents/.tickets/` for the canonical brief or ticket
- `.documents/questions/` for neutral research questions
- `.documents/research/` for evidence-first codebase notes
- `.documents/designs/` for future-state design drafts and approvals
- `.documents/structures/` for slice order and checkpoint artifacts
- `.documents/.plans/` for tactical plans
- `.documents/prs/` for local PR descriptions
- `.documents/thoughts/` for durable notes or debug writeups

The `.latest` files are pointers, not templates. They are expected to change as work moves.
